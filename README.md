# Recipe Card Page

**Veda Technology – Level 1, Day 11**

## Description

A polished, responsive recipe page for Creamy White Sauce Pasta. The page presents the recipe, its timing and serving details, ingredients, step-by-step preparation, and a practical cooking tip in a clean, easy-to-read layout.

## Features

- Semantic HTML5 structure with accessible headings and image description
- Responsive recipe card with a large food photograph
- At-a-glance preparation time, cooking time, servings, and difficulty
- Clearly styled ingredient list and numbered preparation steps
- Cooking tip callout and a link to jump to the recipe
- Mobile, tablet, and desktop layouts
- Reduced-motion support and visible keyboard focus styles

## Technologies used

- HTML5
- CSS3
- Google Fonts (DM Sans and Playfair Display)
- Unsplash image

## How to run locally

1. Download or clone the project files.
2. Open `index.html` in a web browser.

No build tools or dependencies are required. An internet connection is needed to load the Google Fonts and recipe image.
